hermitpy

Reasoner

Classify one ontology. Construct it from an rdflib.graph.Graph already parsed from Turtle, RDF/XML, or another format rdflib accepts.

Reasoner(graph: Graph)
MethodReturnsPurpose
is_consistent()boolWhether the ontology has a model.
unsatisfiable_classes()list[str]Named class IRIs that are empty in every model. If the ontology is inconsistent, every named class is returned.
direct_subclasses()list[tuple[str, str]]Direct (subclass, superclass) IRI pairs. Equivalent classes appear in both directions. Satisfiable classes with no stricter named parent link to owl:Thing. Unsatisfiable classes link to owl:Nothing.
from rdflib import Graph
from hermitpy import Reasoner

graph = Graph()
graph.parse("ontology.ttl")
reasoner = Reasoner(graph)

if reasoner.is_consistent():
    for child, parent in reasoner.direct_subclasses():
        print(child, "rdfs:subClassOf", parent)

OWL fragment

What the reasoner accepts

AcceptedRaises UnsupportedConstruct
Named classes, owl:Thing, owl:Nothing, subclass, equivalence, disjointness, complement, intersection, union, existential and universal object restrictions, inverses, transitive and symmetric object properties, domain, range, class assertions, and object-property assertions. Datatype restrictions and literal assertions, cardinality, property chains, owl:oneOf, role inclusion, keys, owl:sameAs, and SWRL.

direct_subclasses() refuses an inconsistent ontology. It does not classify every class as a subclass of owl:Nothing.
